effect_types.json - for each effect id (the id of an effect put on an entity), whether the game lists it as a Buff (B), DeBuff (D) or passive (P).

Derived from dotnet/Assets/json/buff.json of the Waffle Aion 2 DPS meter (https://github.com/Waffle-ens/waffle_meter), the "type" of each row only;
no names or texts are kept. That file is in turn based on data by hate-jp (https://github.com/HappNJLand/Aion2-Dps-Meter-Packet-Process, MIT).
