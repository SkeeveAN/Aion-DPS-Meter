## 為什麼選擇它

- 即時顯示隊伍或團隊中每位玩家的 DPS、iDPS 和 HPS
- 點擊可穿透的懸浮視窗，不會攔截任何點擊
- 技能明細，含暴擊率和 DPS 曲線
- aiondps.com 上的首領排行榜與公開角色檔案（上傳為選用，預設關閉）
- 互動地圖、活動時間表、世界首領計時器和網路懸浮視窗
- 以語音播報首領施法、戰利品記錄、屬性工具、製作計算器與每日清單
- 安全：被動擷取封包，不讀取記憶體，不注入程式碼
- 免費、開源（MIT），可自動更新

適用於 AION 2 全球版——即 NCSOFT 於 2026 年 10 月 5 日上線的所有地區。韓國和台灣的版本領先數個版本，因此那裡的技能辨識可能不完整。

這是一款適用於 **Aion 2** 的傷害／治療統計器與工具集。它透過 [Npcap](https://npcap.com) 驅動程式讀取您電腦上遊戲本身的網路流量——完全被動：它絕不會送出任何封包，也不會碰觸遊戲處理程序或其記憶體。除非您自行上傳，否則關於您遊玩的任何資料都不會離開您的電腦（參見[上傳](#上傳)）；它送出的另一件事是更新檢查，會向 GitHub 詢問是否有較新的版本，且可以關閉；參見[更新](#更新)。

## 安裝

1. 安裝 [Npcap](https://npcap.com) 驅動程式（統計器需要它才能看到遊戲的流量；它不包含在安裝程式中）。
2. 從[最新版本](../../releases/latest)下載 `AionDpsMeter-win-Setup.exe` 並執行。
   它會安裝到您的使用者設定檔中並啟動統計器——不需要系統管理員權限，也不需要 .NET。
3. 啟動統計器，然後以您的角色登入。統計器會從遊戲本身讀取您的角色、裝備、技能與
   Daevanion 面板；您所在的伺服器會被自動偵測。

## 功能介紹

### 所有人的即時傷害與治療

您隊伍或團隊中的每位玩家都會顯示名稱、總傷害、DPS 與佔比長條；陣營與職業以圖示顯示。可依職業、隊伍或目標篩選。**小怪/首領**篩選可在整體 DPS 與真正的逐目標 **iDPS** 之間切換；首領會依遊戲本身的資料辨識並以名稱顯示。**PVE/PVP** 切換開關將兩者分開，而對首領的團滅會有獨立的一筆紀錄（骷髏圖示代表該次嘗試後首領回到了滿血）。

### 五種檢視，一鍵切換

**傷害**、**治療**、**承受傷害**，以及兩種 **All in One** 檢視。使用快速鍵（預設 **Ctrl+Alt+M**）或點擊浮動層中的模式標籤即可切換。*All in One* 會並排顯示承受傷害、治療與總計，*All in One Compact* 則保留熟悉的 DPS 與總計欄位，並把治療與承受傷害放在名稱下方的小型第二行。

### 可點擊穿透的浮動層

**隱藏介面**會把視窗變成小型標籤（或精簡面板），顯示在 Aion 2 上方，且不會攔截任何一次點擊。不透明度、傷害佔比長條、首領的生命值，以及每位玩家的承受傷害都是可選項目。精簡面板可選擇讓滑鼠點擊穿透到遊戲。浮動層只會在遊戲位於最前方時繪製。可隨時以快速鍵從任何地方切換。

選用（**設定 → 介面 → 開啟遊戲選單時隱藏**，預設關閉）：只要遊戲的某個選單（地圖、背包、軍團、商店、Esc 等）處於開啟狀態，計量器及其浮動層就會讓開，關閉選單後再恢復顯示。它依據滑鼠游標運作：在遊玩時隱藏游標的操作模式下，選單開啟時遊戲會顯示游標；按住顯示游標鍵（預設 Alt）可讓計量器保持顯示，方便你點擊它，而 **Ctrl+Alt+J** 會在目前開啟的選單中顯示浮動層。在經典操作模式下游標一律顯示，因此無法區分選單；計量器會在戰鬥中察覺這一點，並直接保持顯示。

### 每位玩家的技能明細

**雙擊**一位玩家：每個技能的命中次數、爆擊率、總計、最小值、最大值與平均值，並依目標拆分，另附整場戰鬥的 DPS 曲線。爆擊率直接取自伺服器的命中資料，因此十分精確。表格還會顯示技能的命中方式：**背擊**、**正面**、**完美**、**雙重**與**多段**（一次命中包含多次打擊），均以佔其直接命中的比例表示，資料讀取自命中資料。雙重（約兩倍傷害）、完美（小幅加成）與招架已依其造成的傷害核對過；背擊與正面來自一個方向位元組，尚未與遊戲核對，視窗中也會註明這一點。

### 技能循環、增益效果與硬直

同一視窗還有兩個分頁。**技能循環**會把玩家使用過的每個技能，依使用的時刻繪製在時間軸上：輔助技能在上方的軌道，傷害技能在下方，緊接在另一個技能之後穿插的技能則低一行，因此一連串的穿插看起來像一道階梯。背景中是玩家的 DPS（最近五秒的平均值）以及怪物陷入硬直的時刻。拖曳可在戰鬥中移動，**Ctrl + 滾輪**可縮放，將滑鼠停在圖示上可查看該次使用（何時、共幾次中的第幾次、距上一次的時間、當時的 DPS）。下方是**起手**（依序排列的最初幾個技能）和*技能循環概覽*：使用次數、每分鐘、間隔（兩次使用之間的時間）、首次以及傷害占比。**增益效果**列出玩家身上的每個效果及其持續時間、其中來自玩家自身的部分、施加的次數以及施加者；兩名玩家同時維持的效果只計一次。

連同循環資料儲存到檔案的工作階段（見「工作階段」）在載入後會再次顯示循環。

### 首領戰重播（早期測試）

在首領戰的玩家視窗中，**重播**會從上方重現整場戰鬥：您的隊伍以職業配色的圓點顯示，並帶有其最近幾秒的移動軌跡；首領顯示其朝向與生命值；它正在蓄力的技能範圍（蓄力時為琥珀色，命中時變紅——大小仍屬估計時以虛線表示）；被它擊中的人身上有紅圈；陣亡者被劃掉。地圖下方的時間軸顯示首領的大招（琥珀色）、對隊伍的命中（紅色）、死亡、硬直（陰影）以及首領的生命值；點擊或拖曳即可跳到該時刻。播放與暫停（空白鍵），速度從半速到四倍，← 與 → 跳轉五秒，拖曳地圖，滾輪縮放，雙擊重新適應視窗。

位置是遊戲自己的讀數：遊戲隨移動與技能一同傳送，而不是按固定節拍傳送，因此兩個位置之間的移動軌跡以直線繪製。遊戲從不說明攻擊範圍有多大：計量器根據技能擊中了誰來學習每個技能的大小，並在各場戰鬥之間記住。只顯示您的隊伍與首領，絕不顯示其他玩家。一場戰鬥的重播保存在本機歷史中；以舊版本錄製的戰鬥沒有重播。

### 您的整個角色一目了然

**角色**視窗（人形圖示）會顯示遊戲傳送給您的資料：裝備及其道具等級與強化（包含 +15 以上的增幅階段）、神器（Arcana）、種族知識、所有技能及其等級，以及完整的 Daevanion 面板。它會保留您上一次的登入資料，因此不會是空的。將滑鼠移到裝備上可查看詳細資訊（石頭、隨機屬性、神石）。

計量器還會察覺您目前啟用的是哪一組**技能預設**，並保留它見過的每一組預設：技能等級、烙印（Stigma）與石頭。技能分頁會顯示每組預設及其技能的石頭，技能的提示框則以遊戲本身的用語列出石頭，以及烙印所解鎖的效果。

### 屬性計算器（測試版）

更換裝備前先看看屬性變化對傷害的影響。它從遊戲傳送的你自己的屬性出發；你說明主要從哪個方向攻擊（正面、背後、不確定）以及暴擊率，或直接採用上一場戰鬥的資料。在任一屬性中輸入變化，即可對比變化後與目前的傷害，並看到每項屬性提升多少可多得 1%。專家模式增加增益和首領抗性，仍為測試版。結果是估算，因為遊戲的傷害公式並未公布：顯示「多 3.8%」，而不是具體傷害數值。**開始錄製**最多 10 分鐘記錄你的屬性和一場戰鬥的命中；**傳送**會先精確顯示將傳送的內容再上傳——不含名稱、軍團、IP 位址，只有此安裝的隨機識別碼——以便改進計算器。 這個想法來自 [RATmeter](https://github.com/Kuroukihime/AIon2-Dps-Meter) 的 Stat Efficiency Calculator；介面、程式碼和公式均為我們自己的。

### 網路報告

在**工具 → 網路**：**儲存報告**會把最近 15 分鐘的連線情況（延遲、抖動、遺失封包、路由器、網際網路和遊戲伺服器的回應時間、中斷及原因、介面卡類型）寫成格式化的 JSON 檔案 `aiondps_版本_日期_時間.json`，位置由你選擇；**傳送報告**會把同一份報告傳給開發者。報告不含你的 IP 位址和名稱（電腦、Windows 帳戶、介面卡、角色、軍團均不含）；傳送前會有視窗列出包含和不包含的內容。 儲存診斷報告的想法來自 Aletheia 計量器的環境診斷。

### 戰鬥浮動層

一個透明框架，最多包含三個元素，每個元素都可以單獨擺放與調整大小：

- **Boss 施法條：** Boss 一開始施放技能，你就能看到技能名稱、隨剩餘時間縮短的進度條，以及目標是誰（你顯示為紅色）。擊中過多名玩家的技能會標記為**範圍**；**致命**表示你目前受到的該技能最高一擊不低於你目前的生命值。計量器會學習每個技能（是否為範圍技能、傷害何時生效），並在多次工作階段之間記住。
- **目標的目標：** 一個可以整體移動、調整大小和縮放的區塊，其中的各部分也可以在區塊內單獨擺放。如果你用 Tab 選取的目標本身正瞄準某人，你會看到是誰：Boss 顯示圖片與名稱，玩家顯示職業徽章與名稱。**治療者列**（選用）會在區塊中加入該目標的生命條與其身上的減益（或增益）。

在**設定 → 首領戰**中解鎖浮動層以進行配置：拖曳元素主體可移動，拖曳邊緣可調整大小，拖曳角落可縮放；整個框架右下角的握把可同時縮放所有元素。鎖定後它可被點擊穿透，且僅在遊戲位於前景時顯示。所選的 Windows 語音也能以語音**播報首領施法**（可含或不含技能名稱，針對你、針對所有人、致命），即使浮動層已關閉，只要 Aion 位於前景即可；設定中有範例句子可試聽。**Ctrl+Alt+C** 可開關它，*所有浮動層 開 / 關*快速鍵同樣如此。

### 戰利品、屬性與每日清單

**工具**視窗在左側列出這些項目。**戰利品**工具會依工作階段與地圖顯示您從地上撿到的東西，有頁面與浮動層兩種形式（**Ctrl+Alt+L**）。**屬性**工具會顯示帶有您點數的屬性環、每個屬性與領主數值的作用（每點 0.1 %）、所有加成的總和，以及一個數值分頁，說明每項數值及其來自屬性環的佔比。**清單**會記錄您的每日與每週任務，從遊戲中讀取必做的每日任務與每週奧德能量購買，其餘則留給您手動勾選。每個工具都會記住自己的寬度與高度。

### 製作計算器

標記您想製作的配方與次數（可用於整個帳號，讓您的小號也看得到，也可只用於一個角色），**製作計算器**就會逐個配方列出您還缺哪些材料。中間產物會被分解成真正需要採集的東西：三把鐵匠錘需要 18 個錠，也就是 36 個礦石，已有的錠會優先計入。庫存從遊戲中讀取，包括背包、角色倉庫與帳號倉庫，位於倉庫中的材料會註明。可以把頁面開在副螢幕上，或把同一份清單作為遊戲內浮動層顯示（**Ctrl+Alt+R**）。配方來自遊戲本身的資料表；清單的順序決定哪個配方先取得庫存。請登入一次以讀取庫存；在背包與倉庫之間移動的物品會在下次整理後顯示。

### 直播中的計量器（OBS、Streamlabs）

無需拍攝其視窗，即可把計量器即時顯示在遊戲畫面上：開啟 **設定 → 直播 → 啟用 OBS 直播浮動層**，然後使用 **複製 OBS 連結**（或系統匣圖示中的 *複製直播浮動層連結 (OBS)*），在 OBS 或 Streamlabs 中新增 **瀏覽器** 來源，貼上連結並設定來源的大小。該頁面即時跟隨計量器：目前檢視（傷害、治療、承受傷害，合為一體）、帶職業圖示和進度條的玩家，以及首領的生命值。在連結後加上 `?scale=1.5` 或 `?rows=5` 即可放大或減少顯示的列數。

也支援**兩台電腦**（一台執行遊戲，另一台執行 OBS）：把連結複製到直播電腦，連結包含遊戲電腦在您網路中的位址。只有您自己的網路能存取，網際網路不行；連結包含隨機金鑰（**新金鑰**會使舊連結失效），只提供 `GET`，頁面不會從其他地方載入任何內容，也不會向任何人傳送資料。Windows 可能會詢問一次是否在防火牆中允許計量器：請為私人網路允許。玩家名稱**預設關閉**——每個人依職業顯示，與上傳時相同——可在同一設定卡中開啟。

## 使用方式

統計器一執行就會開始記錄。**暫停會直接捨棄**而不是延後處理：暫停期間的事件會被永久略過，因此繼續時絕不會重播您沒參與的戰鬥。

- **複製**會把一行、可直接貼到聊天的排名放進剪貼簿（`Name 1.234.567 (890), …`）；**全部複製**
  則提供 Discord markdown 表格。
- 外觀在**設定 → 介面**中設定：佈景主題（深色／淺色）、字型大小、語言、浮動層外觀與不透明度、隨 Windows 自動啟動。
- 您的設定不怕當機：設定檔是一次性寫入的，旁邊還保留著上次啟動時的副本。如果檔案損毀，會自動還原該副本（損毀的檔案會保留在旁邊）。**設定 → 一般 → 將所有設定還原為預設值**會確認兩次，並可在 30 秒內復原；您的上傳與隱私選擇、更新檢查以及您的角色維持不變。

## 上傳

- **首領戰鬥**會在您點擊上傳時上傳（工具列按鈕、戰鬥記錄選單或 **Ctrl+Alt+U**）：包含首領、參戰玩家、傷害、治療、承受傷害與技能。只接受遊戲有公告且目錄中已收錄的首領。自動上傳可用，且**預設關閉**。
- **您自己的角色檔案**（名稱、職業、等級、裝備、技能、Daevanion、軍團、伺服器、陣營）可在登入後幾秒自動上傳，讓您能在網站上被找到。這**預設關閉**；請在**設定**中開啟。
- 未上傳時，任何資料都不會離開您的電腦。

## 更新

統計器會自行更新。它會在啟動時以及執行期間每五分鐘向 GitHub 詢問是否有較新的版本，在背景下載，並於下次啟動時換上——不需要安裝程式，也不會跳出 UAC 提示。更新就緒時，狀態列會出現一行綠色文字（透明浮動層上則會出現徽章）；點擊它即可選擇立即重新啟動。**應用程式 → 檢查更新**可隨時手動執行同樣的動作。舊版本在新版本發布後仍可繼續上傳 72 小時，之後就必須更新。

檢查只會讀取一個 URL，除了請求本身外不會送出任何內容：

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

可在**設定 → 更新**中關閉；即使關閉，選單項目仍可使用。

## 從原始碼建置

```
cd Client
dotnet build
dotnet run -- selftest                              # self-checks (protocol, capture, decoding, ...)
dotnet run -- aion2-record <out.jsonl>              # record the game's traffic ("stop" ends it)
dotnet run -- aion2-replay <file.jsonl>             # replay a recording through the real decoder
dotnet run -- aion2-upload-dryrun <file.jsonl>      # build the uploads of a recording, send nothing
```

僅支援 Windows（WPF）。`Tools/aion2-dat` 會讀取遊戲的文字表（八種語言的名稱）；請參閱其 README。
