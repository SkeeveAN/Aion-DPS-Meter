## 为什么选择它

- 实时显示队伍或团队中每位玩家的 DPS、iDPS 和 HPS
- 点击可穿透的悬浮窗，不会拦截任何点击
- 技能明细，含暴击率和 DPS 曲线
- aiondps.com 上的首领排行榜与公开角色档案（上传为可选，默认关闭）
- 互动地图、活动时间表、世界首领计时器和网络悬浮窗
- 语音播报首领施法、拾取记录、属性工具、制作计算器和每日清单
- 被动：仅被动抓包，不读取内存，不注入代码，不向游戏发送任何内容
- 免费、开源（MIT），可自动更新

适用于 AION 2 全球版——即 NCSOFT 于 2026 年 10 月 5 日开服的所有地区。韩国和台湾的版本领先数个版本，因此那里的技能识别可能不完整。

适用于 **Aion 2** 的伤害/治疗统计工具和工具箱。它通过 [Npcap](https://npcap.com) 驱动在您的电脑上读取游戏自身的网络流量——纯被动：
从不发送数据包，也不触碰游戏进程及其内存。除非您主动上传（见[上传](#上传)），否则您的游戏数据不会离开电脑；
另外会发送的只有更新检查，即询问 GitHub 是否有新版本，可以关闭；见[更新](#更新)。

## 安装

1. 安装 [Npcap](https://npcap.com) 驱动（工具需要它才能看到游戏流量；它不包含在安装程序中）。
2. 从[最新发布](../../releases/latest)下载 `AionDpsMeter-win-Setup.exe` 并运行。
   它安装到您的用户目录并启动工具——无需管理员权限，也无需 .NET。
3. 启动工具，然后用您的角色登录。工具会从游戏本身读取角色、装备、技能和
   Daevanion 面板；所在服务器会被自动识别。

## 功能介绍

### 所有人的实时伤害与治疗

您队伍或团队中的每位玩家都会显示名称、总伤害、DPS 和占比条；阵营和职业以图标显示。可按职业、队伍或目标过滤。**Mob/Boss** 过滤器在整体 DPS 与按目标计算的真实 **iDPS** 之间切换；
首领由游戏自身数据识别并按名称显示。**PVE/PVP** 开关将两者分开，首领战团灭会有单独的一条记录（骷髅图标表示该次尝试之后首领恢复了满血）。

### 五种视图，一键切换

**伤害**、**治疗**、**承受伤害**和两种**综合**视图。用快捷键切换
（默认 **Ctrl+Alt+M**），或点击悬浮窗中的模式标签。*综合*并排显示承受伤害、
治疗和总计，*All in One Compact* 保留熟悉的 DPS 和总计列，并把
治疗和承受伤害放在名称下方的小号第二行。

### 可穿透点击的悬浮窗

**隐藏界面**（Hide UI）把窗口变成小标签（或紧凑面板），悬浮在 Aion 2 上方，
不会吞掉任何一次点击。不透明度、伤害占比条、首领血量和每位玩家的承受伤害均可作为选项。紧凑面板可选择让鼠标点击穿透到游戏。悬浮窗只在游戏位于前台时绘制。可随时随地用快捷键切换。

可选（**设置 → 界面 → 打开游戏菜单时隐藏**，默认关闭）：只要游戏的某个菜单（地图、背包、军团、商店、Esc 等）处于打开状态，计量器及其悬浮窗就会让开，关闭菜单后再恢复显示。它依据鼠标光标工作：在游戏时隐藏光标的操作模式下，菜单打开时游戏会显示光标；按住显示光标键（默认 Alt）可让计量器保持显示，方便你点击它，而 **Ctrl+Alt+J** 会在当前打开的菜单中显示悬浮窗。在经典操作模式下光标始终显示，因此无法区分菜单；计量器会在战斗中察觉到这一点，并直接保持显示。

### 每位玩家的技能明细

**双击**玩家：显示每个技能的命中数、暴击率、总计、最小值、最大值和平均值，
按目标拆分，并附有整场战斗的 DPS 曲线。暴击率直接取自服务器的命中数据，因此是精确的。表格还会显示技能的命中方式：**背击**、**正面**、**完美**、**双重**和**多段**（一次命中包含多次打击），均以占其直接命中的比例表示，数据读取自命中数据。双重（约两倍伤害）、完美（小幅加成）和招架已根据其造成的伤害核对过；背击和正面来自一个方向字节，尚未与游戏核对，窗口中也会注明这一点。

### 技能循环、增益效果与硬直

同一窗口还有两个标签页。**技能循环**会把玩家使用过的每个技能，按使用的时刻绘制在时间轴上：辅助技能在上方的轨道，伤害技能在下方，紧接在另一个技能之后穿插的技能则低一行，因此一连串的穿插看起来像一道阶梯。背景中是玩家的 DPS（最近五秒的平均值）以及怪物陷入硬直的时刻。拖动可在战斗中移动，**Ctrl + 滚轮**可缩放，将鼠标悬停在图标上可查看该次使用（何时、共几次中的第几次、距上一次的时间、当时的 DPS）。下方是**起手**（按顺序排列的最初几个技能）和*技能循环概览*：使用次数、每分钟、间隔（两次使用之间的时间）、首次以及伤害占比。**增益效果**列出玩家身上的每个效果及其持续时间、其中来自玩家自身的部分、施加的次数以及施加者；两名玩家同时维持的效果只计一次。

随循环数据保存到文件的会话（见“会话”）在加载后会再次显示循环。

### 首领战回放（早期测试）

在首领战的玩家窗口中，**回放**会从上方重现整场战斗：您的队伍以职业配色的圆点显示，并带有其最近几秒的移动轨迹；首领显示其朝向和生命值；它正在蓄力的技能范围（蓄力时为琥珀色，命中时变红——大小仍属估算时用虚线）；被它击中的人身上有红圈；阵亡者被划掉。地图下方的时间轴显示首领的大招（琥珀色）、对队伍的命中（红色）、死亡、硬直（阴影）以及首领的生命值；点击或拖动即可跳到该时刻。播放与暂停（空格键），速度从半速到四倍，← 和 → 跳转五秒，拖动地图，滚轮缩放，双击重新适应窗口。

位置是游戏自己的读数：游戏随移动和技能一同发送，而不是按固定节拍发送，因此两个位置之间的移动轨迹以直线绘制。游戏从不说明攻击范围有多大：计量器根据技能击中了谁来学习每个技能的大小，并在各场战斗之间记住。只显示您的队伍和首领，绝不显示其他玩家。一场战斗的回放保存在本地历史中；用旧版本录制的战斗没有回放。

### 一眼看清您的整个角色

**角色**窗口（人形图标）显示游戏发送的关于您自己的数据：含物品等级与
强化的装备（包括 +15 以上的增幅阶段）、奥术、种族知识、含等级的所有技能，
以及完整的 Daevanion 面板。它会保留您上次登录的数据，因此从不为空。将鼠标悬停在装备上可查看
详情（魔石、随机属性、神石）。

计量器还会识别您当前启用的是哪个**技能预设**，并保留它见过的每个预设：技能等级、烙印和魔石。技能标签页会显示每个预设及其技能的魔石，技能提示会用游戏自己的文字列出魔石以及烙印所解锁的效果。

### 属性计算器（测试版）

更换装备前先看看属性变化对伤害的影响。它从游戏发送的你自己的属性出发；你说明主要从哪个方向攻击（正面、背后、不确定）以及暴击率，或直接采用上一场战斗的数据。在任意属性中输入变化，即可对比变化后与当前的伤害，并看到每项属性提升多少可多得 1%。专家模式增加增益和首领抗性，仍为测试版。结果是估算，因为游戏的伤害公式并未公布：显示“多 3.8%”，而不是具体伤害数值。**开始录制**最多 10 分钟记录你的属性和一场战斗的命中；**发送**会先精确展示将发送的内容再上传——不含名称、军团、IP 地址，只有此安装的随机标识——以便改进计算器。 这个想法来自 [RATmeter](https://github.com/Kuroukihime/AIon2-Dps-Meter) 的 Stat Efficiency Calculator；界面、代码和公式均为我们自己的。

### 网络报告

在**工具 → 网络**：**保存报告**会把最近 15 分钟的连接情况（延迟、抖动、丢包、路由器、互联网和游戏服务器的响应时间、中断及原因、适配器类型）写成格式化的 JSON 文件 `aiondps_版本_日期_时间.json`，位置由你选择；**发送报告**会把同一份报告发给开发者。报告不含你的 IP 地址和名称（电脑、Windows 账户、适配器、角色、军团均不含）；发送前会有窗口列出包含和不包含的内容。 保存诊断报告的想法来自 Aletheia 计量器的环境诊断。

### 战斗悬浮窗

一个透明框架，最多包含三个元素，每个元素都可以单独摆放和调整大小：

- **Boss 施法条：** Boss 一开始施放技能，你就能看到技能名称、随剩余时间缩短的进度条，以及目标是谁（你显示为红色）。击中过多名玩家的技能会标记为**范围**；**致命**表示你目前受到的该技能最高一击不低于你当前的生命值。计量器会学习每个技能（是否为范围技能、伤害何时生效），并在多次会话之间记住。
- **目标的目标：** 一个可以整体移动、调整大小和缩放的区块，其中的各部分也可以在区块内单独摆放。如果你用 Tab 选中的目标本身正瞄准某人，你会看到是谁：Boss 显示图片和名称，玩家显示职业徽章和名称。**治疗者栏**（可选）会在区块中加入该目标的生命条及其身上的减益（或增益）。

在**设置 → 首领战**中解锁悬浮窗以进行布置：拖动元素主体可移动，拖动边缘可调整大小，拖动角落可缩放；整个框架右下角的手柄可同时缩放所有元素。锁定后它可被点击穿透，并且仅在游戏位于前台时显示。所选的 Windows 语音还可以**语音播报首领施法**（可带或不带技能名称，针对您、针对所有人、致命），即使悬浮窗已关闭，只要 Aion 位于前台也能播报；设置中有可试听的示例语句。**Ctrl+Alt+C** 可开关它，*所有悬浮窗 开 / 关*热键同样如此。

### 拾取、属性与每日清单

**工具**窗口在左侧列出这些功能。**拾取**工具按会话和地图显示您从地上拾取的物品，提供页面和悬浮窗两种形式（**Ctrl+Alt+L**）。**属性**工具显示带有您点数的属性环、每个属性和领主数值的作用（每点 0.1 %）、所有加成的总和，以及一个属性标签页，解释每项属性及其来自属性环的占比。**清单**记录您的每日和每周任务，从游戏中读取必做的每日任务和每周的奥德能量购买，其余的留给您手动勾选。每个工具都会记住自己的宽度和高度。

### 制作计算器

标记您想制作的配方及次数（可用于整个账号，这样您的小号也能看到，也可只用于一个角色），**制作计算器**就会逐个配方列出您还缺哪些材料。中间产物会被分解成真正需要采集的东西：三把铁匠锤需要 18 个锭，即 36 个矿石，已有的锭会优先计入。库存从游戏中读取，包括背包、角色仓库和账号仓库，位于仓库中的材料会注明。可以把页面开在副屏上，或把同一份清单作为游戏内悬浮窗显示（**Ctrl+Alt+R**）。配方来自游戏自身的数据表；清单的顺序决定哪个配方先获得库存。请登录一次以读取库存；在背包与仓库之间移动的物品会在下次整理后显示。

### 直播中的计量器（OBS、Streamlabs）

无需拍摄其窗口，即可把计量器实时显示在游戏画面上：开启 **设置 → 直播 → 启用 OBS 直播悬浮窗**，然后使用 **复制 OBS 链接**（或托盘图标中的 *复制直播悬浮窗链接 (OBS)*），在 OBS 或 Streamlabs 中添加 **浏览器** 源，粘贴链接并设置源的大小。该页面实时跟随计量器：当前视图（伤害、治疗、承受伤害，合为一体）、带职业图标和进度条的玩家，以及首领的生命值。在链接后添加 `?scale=1.5` 或 `?rows=5` 即可放大或减少显示的行数。

也支持**两台电脑**（一台运行游戏，另一台运行 OBS）：把链接复制到推流电脑，链接包含游戏电脑在您网络中的地址。只有您自己的网络能访问，互联网不能；链接包含随机密钥（**新密钥**会使旧链接失效），只提供 `GET`，页面不会从其他地方加载任何内容，也不会向任何人发送数据。Windows 可能会询问一次是否在防火墙中允许计量器：请为专用网络允许。玩家名称**默认关闭**——每个人按职业显示，与上传时相同——可在同一设置卡中开启。

## 使用方法

工具一运行就开始记录。**暂停是丢弃而非延后**：暂停期间的
事件会永久丢失，恢复时绝不会补录您没参与的战斗。

- **Copy** 把一行可直接发到聊天的排名放入剪贴板（`名称 1.234.567 (890), …`）；**Copy All**
  给出适用于 Discord 的 Markdown 表格。
- 外观在**设置 → 界面**中设置：主题（深色/浅色）、字体大小、语言、悬浮窗样式
  和不透明度、随 Windows 启动。
- 您的设置不怕崩溃：设置文件是一次性写入的，旁边还保留着上次启动时的副本。如果文件损坏，会自动恢复该副本（损坏的文件会保留在旁边）。**设置 → 常规 → 将所有设置恢复默认**会确认两次，并可在 30 秒内撤销；您的上传和隐私选择、更新检查以及您的角色保持不变。

## 上传

- **首领战斗**在您点击上传（工具栏按钮、会话菜单或 **Ctrl+Alt+U**）时上传：
  首领、参战玩家、伤害、治疗、承受伤害和技能。仅接受游戏宣布且目录已知的首领。自动上传可用，但**默认关闭**。
- **您自己的角色资料**（名称、职业、等级、装备、技能、Daevanion、军团、服务器、阵营）可
  在登录后几秒自动上传，以便在网站上被找到。默认**关闭**；可在**设置**中开启。
- 不上传时，任何数据都不会离开您的电脑。

## 更新

工具会自行更新。它在启动时以及运行期间每五分钟询问 GitHub 是否有新版本，
在后台下载，并在下次启动时替换——无需安装程序，也没有 UAC
提示。更新就绪时，状态栏会出现一行绿色文字（透明悬浮窗上会出现一个徽标）；
点击它即可选择立即重启。**应用 → 检查更新**可按需执行同样操作。
旧版本在新版本发布后仍可继续上传 72 小时，之后必须更新。

检查只读取一个 URL，除请求本身外不发送任何内容：

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

可在**设置 → 更新**中关闭；菜单项在关闭后仍可使用。

## 从源码构建

```
cd Client
dotnet build
dotnet run -- selftest                              # 自检（协议、抓包、解码……）
dotnet run -- aion2-record <out.jsonl>              # 录制游戏流量（输入 "stop" 结束）
dotnet run -- aion2-replay <file.jsonl>             # 用真实解码器回放录制
dotnet run -- aion2-upload-dryrun <file.jsonl>      # 构建录制的上传内容，不发送任何东西
```

仅限 Windows（WPF）。`Tools/aion2-dat` 读取游戏的文本表（八种语言的名称）；见其 README。
