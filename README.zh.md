# Aion DPS Meter

一个专为 **AION 4.6（OriginAion）** 打造的伤害与掉落统计工具，完全基于游戏自身的 `Chat.log`
文件运行。

它读取的是客户端自己写入的一个文本文件。它不会捕获网络流量，也不会读取或写入游戏进程。你的游戏
数据不会离开你的电脑——没有伤害数字，没有掉落物，没有名字。它唯一发送的东西是更新检查，向
GitHub 询问是否有新版本，并且可以关闭；见[更新](#更新)。

## 安装

1. 从[最新版本](../../releases/latest)下载 `AionDpsMeter-win-Setup.exe` 并运行。无需点选任何
   选项——它会安装到你的用户配置文件中并启动统计工具。无需管理员权限，无需 .NET。
2. 打开 **Settings → App Settings**，选择 **Aion 安装文件夹**——即包含 `bin64\game.dll` 的根
   文件夹。对话框会立即告诉你是否找到了有效的安装，以及那里是否已经存在 `Chat.log`。

> **从 0.5.2 或更早版本升级？** 先卸载旧版本（Windows 设置 → 应用 → *Aion DPS Meter*），再运行
> 新的安装程序。那些版本安装在 `Program Files` 中，所以它们永远无法自我更新。这只是一次性的步
> 骤——从此以后更新会自动应用。

### 前提条件：客户端的聊天记录功能必须开启

只有当客户端内部选项 `g_chatlog` 启用时，Aion 才会写入 `Chat.log`。这个开关在游戏客户端里，
不在本工具里——按你平时的方式开启它（例如使用
[ShugoConsole](https://github.com/grenadium/ShugoConsole)）。**Aion DPS Meter 为此绝不会触碰游
戏进程**；如果文件没有被写入，统计工具就没有东西可读。

## 使用方法

只要统计工具在运行，并且设置了有效的 Aion 文件夹，记录就会立即开始。

**它绝不会读取你的聊天历史。** 启动时它会跳到 `Chat.log` 的*当前*末尾，只处理从那一刻起写入
的行——就像刚刚打开的录音机，而不是档案扫描器。**暂停会丢弃**而不是推迟：暂停期间写入的行会
被永久跳过，因此恢复记录时绝不会重放你有意错过的战斗。你过去的私聊、军团聊天和悄悄话永远不会
被查看。

### 视图

- **Dmg（伤害）**——每位玩家的伤害，含总量与 DPS、职业图标和可排序列表。**Mob/Boss** 过滤器
  会在整体 DPS 与真正的按目标 **iDPS**（对某一目标造成的伤害除以小队与该目标的共同交战时长）
  之间切换该列。
- **Loot（掉落）**——谁获得了什么：人物、物品、数量与稀有度等级。圣物同时计入该人物的深渊点数。

### Hide UI（悬浮层）

将窗口变成一组小型、可穿透点击的悬浮条，可以留在游戏画面之上——每位玩家一个，显示名字、伤害
和 DPS。可随时用 **Ctrl+Alt+H** 切换，因此绝不是有去无回的单行道。

### Copy（复制）

**Copy** 会将一行、可直接发送到聊天的排行榜复制到剪贴板（`名字 1,234,567 (890)，…`）。在
Loot 视图下，它会改为生成一段 Aion 聊天格式的掉落汇总；**Copy All** 则给出一个 Discord
Markdown 表格。

### 游戏内命令

像普通聊天一样输入以下命令，即可在不离开游戏的情况下控制统计工具：

| 命令 | 效果 |
|---|---|
| `.ui` | 切换 Hide-UI 悬浮层 |
| `.pause` / `.resume` | 暂停 / 继续记录 |
| `.dmg` | 将伤害排行复制到剪贴板 |
| `.cleardmg` | 清除当前会话 |
| `.loot` | 将掉落汇总复制到剪贴板 |

只有在设置中登记过的角色才能触发这些命令，因此在你根本没在看的频道里，陌生人输入的
`.cleardmg` 无法清空你的会话。

## 更新

统计工具会自我更新。启动时以及此后每五分钟，它都会向 GitHub 询问是否有更新版本，在后台下载，
并在下次启动时替换。无需安装程序，无需 UAC 弹窗，无需点击任何东西。之所以能这样，是因为程序
安装在用户配置文件中，而不是 `Program Files`——在那里它才被允许替换自己的文件。

一旦更新下载完成，底部状态栏会出现一行绿色文字；点击它可以立即重启应用新版本。忽略它不会有任
何损失——版本已经就绪，会在下次正常启动时生效。这里刻意没有弹窗：窗口悬浮在正在运行的游戏之
上，一个在 Boss 战斗中途抢走焦点的对话框，比稍晚一点更新更糟糕。

**App → Check for updates** 可以按需做同样的检查，并且在你已是最新版本时也会告知你。

该检查只读取一个 URL，除请求本身外不发送任何内容：

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

可在 **Settings → App Settings → Updates** 中关闭。菜单项依然可用——那是你主动的请求，而不是
程序自行做出的决定。

## 准确度如何？

已针对同一次 Sauro 补给基地副本记录的三份 `Chat.log`（分别来自三台不同电脑，其中一台是德语客
户端）进行了校验，并以 Boss 的真实生命值作为基准。每个 Boss 的统计伤害与其真实生命值相差
**0.02% – 2.8%**：

| Boss | 真实生命值 | 统计值 | 偏差 |
|---|---|---|---|
| 卫队长阿胡拉迪姆 | 1,736,993 | 1,737,299 | +0.02% |
| 暗黑吞噬者德拉卡纳克 | 1,343,657 | 1,347,258 | +0.27% |
| 检查官萨亚胡姆 | 1,377,644 | 1,370,734 | −0.50% |
| 补给指挥官拉诺迪姆 | 489,332 | 503,244 | +2.84% |

其余差异来自终结一击时的过量伤害，任何基于日志的统计工具都无法看到这部分。玩家的总伤害在三台
电脑上精确到个位数都完全一致。

两个已知且无害的偏差：某个 Boss 的护盾会吸收伤害，但这部分伤害仍会被记录（因此总量会超过其
生命值）；多个同名怪物会被合并统计。

## 从源码构建

```
dotnet build
dotnet run -- selftest                    # 解析器与 DPS 计算的自检测试
dotnet run -- chatlog <Chat.log 路径>      # 解析文件并输出摘要
```

仅支持 Windows（WPF）。自检测试会运行来自所有支持语言的真实日志中的原文行，是判断某次解析器
改动是否破坏了什么的最快方法。

## 关于服务器规则的说明

本工具只读取游戏自身生成的一个日志文件。尽管如此，私服通常都有自己关于第三方软件和插件的规
定——使用前最好先看看 OriginAion 的相关规定。
