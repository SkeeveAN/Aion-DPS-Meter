# Aion DPS Meter

带有社区首领排行榜和角色资料的网站：**https://aiondps.com**

适用于**《永恒之塔2》**的伤害/治疗统计工具。它通过 [Npcap](https://npcap.com) 驱动在您的电脑上读取游戏的网络流量——纯被动：
从不发送数据包，也不触碰游戏进程及其内存。除非您主动上传（见[上传](#上传)），否则您的游戏数据不会离开电脑；另外会发送更新检查，
即询问 GitHub 是否有新版本，可以关闭；见[更新](#更新)。

> 经典版永恒之塔（基于 Chat.log）不再属于本工具。支持它的最后一个版本保留在分支
> [`aion1-included`](../../tree/aion1-included) 上。

## 安装

1. 安装 [Npcap](https://npcap.com) 驱动（工具需要它才能看到游戏流量；它不包含在安装程序中）。
2. 从[最新发布](../../releases/latest)下载 `AionDpsMeter-win-Setup.exe` 并运行。它安装到您的用户目录并启动工具——无需管理员权限，也无需 .NET。
3. 启动工具，然后用您的角色登录。工具会从游戏本身读取角色、装备、技能和 Daevanion 面板；所在服务器会被自动识别。

## 使用

工具一运行就开始记录。**暂停是丢弃而非延后**：暂停期间的事件会永久丢失，恢复时绝不会补录您没参与的战斗。

### 视图

- **Dmg** — 每位玩家的伤害，含总计和 DPS、职业图标和可排序列表。**Mob/Boss** 过滤器在整体 DPS 与按目标计算的真实 **iDPS** 之间切换。
  首领由游戏自身数据识别并按名称显示。**双击**玩家可查看技能明细。
- **角色**（人形图标）— 打开显示您自己角色的窗口：资料、含物品等级与强化的装备、含等级的技能以及 Daevanion 面板。
  它会保留您上次登录的数据，因此从不为空。

### Hide UI（悬浮层）

把窗口变成悬在游戏上方、可穿透点击的小标签——每位玩家一个，显示名称、伤害和 DPS。可随处用 **Ctrl+Alt+H** 切换。

### 复制

**Copy** 把一行可直接发到聊天的排名放入剪贴板（`名称 1.234.567 (890), …`）；**Copy All** 给出适用于 Discord 的 Markdown 表格。

### 聊天命令

`.ui`（悬浮层）、`.pause` / `.resume`、`.dmg`（复制排名）和 `.cleardmg`（清空本次记录）。处理程序只接受来自您自己角色的命令。
《永恒之塔2》的聊天尚未解码，因此目前它们不起作用。

## 上传

- **首领战斗**在您点击上传（按钮或 Session 菜单）时上传：首领、参战玩家、伤害、治疗、承受伤害和技能。仅接受游戏宣布且目录已知的首领。
- **您自己的角色资料**（名称、职业、等级、装备、技能、Daevanion、军团、服务器）会在登录后几秒自动上传，以便在网站上被找到。可在**设置**中关闭。
- 不上传时，任何数据都不会离开您的电脑。

## 更新

工具会自行更新。它在启动时以及每五分钟询问 GitHub 是否有新版本，在后台下载，并在下次启动时应用——无需安装程序，也没有 UAC 提示。
更新就绪时底部会出现一行绿色文字；点击即可选择立即重启。**App → Check for updates** 可按需执行同样操作。

检查只读取一个 URL，除请求本身外不发送任何内容：

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

可在**设置 → 更新**中关闭；菜单项在关闭后仍可使用。

## 从源码构建

```
cd Client
dotnet build
dotnet run -- selftest                              # 自检（协议、抓包、解码……）
dotnet run -- aion2-record <out.jsonl>              # 录制游戏流量（输入 "stop" 结束）
dotnet run -- aion2-replay <文件.jsonl>             # 用真实解码器回放录制
dotnet run -- aion2-upload-dryrun <文件.jsonl>      # 构建录制的上传内容，不发送任何东西
```

仅限 Windows（WPF）。`Tools/aion2-dat` 读取游戏的文本表（八种语言的名称）；见其 README。

## 关于服务器规则的说明

本工具只被动观察游戏自身的网络流量。尽管如此，运营方会对第三方工具制定自己的规则——使用前请先查看游戏的条款。
