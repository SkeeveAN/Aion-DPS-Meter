# Aion DPS Meter

**Бесплатный счётчик DPS для AION 2** — урон и лечение всей группы в реальном времени, оверлей, пропускающий клики, рейтинги боссов, карта питомцев и сбора ресурсов, расписание событий и таймеры мировых боссов. Для Windows, с открытым кодом и никогда не читает память игры.

## Почему стоит выбрать

- DPS, iDPS и HPS в реальном времени для каждого игрока группы или рейда
- Оверлей, который не перехватывает клики
- Разбор умений с шансом крита и кривой DPS
- Рейтинги боссов и публичные профили персонажей на aiondps.com (загрузка по желанию, по умолчанию выключена)
- Интерактивная карта, расписание событий, таймеры мировых боссов и сетевой оверлей
- Безопасно: пассивный перехват пакетов, без чтения памяти и внедрения кода
- Бесплатно, с открытым кодом (MIT) и обновляется сам

Работает с глобальной версией AION 2 — со всеми регионами, запущенными NCSOFT 5 октября 2026 года. Корея и Тайвань на несколько версий впереди, поэтому там распознавание умений может быть неполным.

Счётчик урона/лечения и набор инструментов для **Aion 2**. Он читает сетевой трафик самой игры на вашем компьютере
через драйвер [Npcap](https://npcap.com) — пассивно: никогда не отправляет пакеты и не касается ни процесса игры, ни его
памяти. Ничего из вашей игры не покидает компьютер, пока вы сами это не загрузите (см.
[Загрузки](#загрузки)); кроме того, отправляется проверка обновлений — запрос к GitHub о более новой
версии, её можно отключить; см. [Обновления](#обновления).

## Установка

1. Установите драйвер [Npcap](https://npcap.com) (он нужен счётчику, чтобы видеть трафик игры; в установщик он
   не входит).
2. Скачайте `AionDpsMeter-win-Setup.exe` из [последнего релиза](../../releases/latest) и запустите. Он ставится
   в профиль пользователя и запускает счётчик — без прав администратора и без .NET.
3. Запустите счётчик, затем войдите в игру своим персонажем. Счётчик считывает персонажа, снаряжение, умения и доски
   Даэваниона из самой игры; сервер, на котором вы играете, определяется автоматически.

## Что он умеет

### Урон и лечение всех игроков в реальном времени

Каждый игрок вашей группы или рейда с именем, общим уроном, DPS и полосой доли; фракция и класс показаны
значками. Фильтр по классу, группе или цели. Фильтр **Mob/Boss** переключает между общим DPS и
настоящим **iDPS** по цели; боссы распознаются по данным самой игры и показываются по имени. Переключатель
**PvE/PvP** разделяет эти два режима, а вайп на боссе получает собственную запись (череп отмечает попытку,
после которой босс снова получил полное здоровье).

### Пять видов, один щелчок между ними

**Урон**, **Лечение**, **Полученный урон** и два вида **Всё вместе**. Переключайте горячей клавишей
(по умолчанию **Ctrl+Alt+M**) или щелчком по подписи режима в оверлее. *Всё вместе* показывает полученный урон,
лечение и общий урон рядом, *All in One Compact* сохраняет привычные столбцы DPS и общего урона, а лечение
и полученный урон выводит маленькой второй строкой под именем.

### Кликабельно-прозрачный оверлей

**Hide UI** превращает окно в маленькие плашки (или компактную панель), которые лежат поверх Aion 2 и не
перехватывают ни одного щелчка. Непрозрачность, полосы доли урона, здоровье босса и полученный урон по игрокам —
это настройки. Оверлей рисуется, только пока игра на переднем плане. Включайте его откуда угодно горячей клавишей.

Необязательно (**Настройки → Интерфейс → Скрывать при открытых меню игры**, по умолчанию выключено): счётчик и его оверлеи уступают место, пока открыто одно из меню игры (карта, инвентарь, легион, магазин, Esc ...), и возвращаются, когда ты его закрываешь. Работает это по курсору мыши: в режиме управления, который скрывает курсор во время игры, игра показывает его при открытии меню; если удерживать клавишу показа курсора (по умолчанию Alt), счётчик остаётся на экране и по нему можно кликнуть, а **Ctrl+Alt+J** показывает оверлеи при открытом меню. В классическом режиме управления курсор виден всегда, поэтому меню не различить; счётчик замечает это во время боя и просто остаётся на экране.

### Разбивка по умениям для каждого игрока

**Двойной щелчок** по игроку: каждое умение с числом попаданий, шансом крита, суммой, минимумом, максимумом и средним,
с разбивкой по целям, плюс кривая DPS за весь бой. Шанс крита читается прямо из данных сервера о попаданиях, поэтому он точный. Таблица также показывает, как прошли удары умения: **Сзади**, **Спереди**, **Идеально**, **Двойной** и **Мульти** (несколько ударов в одном попадании) в виде доли его прямых попаданий, по данным о попаданиях. Двойной (примерно двойной урон), Идеально (небольшой бонус) и Парирование проверены по урону, который они наносят; «Сзади» и «Спереди» берутся из байта направления, который ещё не сверен с игрой, и окно сообщает об этом.

### Ротация, эффекты и оглушение

В том же окне есть ещё две вкладки. **Ротация** рисует на временной шкале каждое умение, которое использовал игрок, в момент его использования: умения поддержки на верхней дорожке, умения урона ниже, а умение, вплетённое сразу после другого, — на строку ниже, так что череда вплетений выглядит как лестница. На заднем плане идут DPS игрока (среднее за последние пять секунд) и моменты, когда монстр был оглушён. Перетаскивайте, чтобы двигаться по бою, **Ctrl + колесо** масштабирует, а при наведении на значок показывается использование (когда, какое по счёту из скольких, время с предыдущего, DPS в тот момент). Ниже находятся **Начало** (первые умения по порядку) и *ротация вкратце*: Исп., В мин., Интервал между двумя использованиями, Первый и доля урона. **Эффекты** перечисляет каждый эффект, который был на игроке, с его временем действия, долей, пришедшейся на самого игрока, количеством наложений и тем, кто его дал; эффект, который двое игроков поддерживали одновременно, считается один раз.

Бой сохраняет эти данные в локальной истории, поэтому старого босса можно посмотреть снова; бои, записанные более старой версией, ротацию не показывают.

### Повтор боя с боссом (ранний тест)

В окне игрока для боя с боссом кнопка **Повтор** воспроизводит бой сверху: ваша группа в виде точек цвета класса с последними секундами их пути, босс с направлением взгляда и здоровьем, зоны умений, которые он готовит (янтарные во время подготовки, красные в момент удара — пунктиром, пока размер лишь предположение), красное кольцо на том, кого он задел, погибшие перечёркнуты. Под картой временная шкала показывает большие атаки босса (янтарные), удары по группе (красные), смерти, оглушения (затенены) и здоровье босса; щёлкните или потяните по ней, чтобы перейти к этому моменту. Воспроизведение и пауза (пробел), скорость от половинной до четырёхкратной, ← и → перематывают на пять секунд, перетаскивайте карту, колесо для масштаба, двойной щелчок — снова вписать.

Позиции — это собственные показания игры: она присылает их вместе с движениями и умениями, а не через равные промежутки, поэтому путь между двумя позициями рисуется прямой. Игра никогда не сообщает размер зоны атаки: метр узнаёт размер каждого умения по тому, кого оно задело, и запоминает его между боями. Показываются только ваша группа и боссы, никогда другие игроки. Бой хранит свой повтор в локальной истории; у боёв, записанных старой версией, его нет.

### Боевой оверлей

Одна прозрачная рамка с тремя элементами (максимум), каждый из которых ты размещаешь и масштабируешь отдельно:

- **Полоса каста босса:** в момент, когда босс начинает умение, ты видишь его название, убывающую полосу с оставшимся временем и того, на кого оно направлено (ты — красным). Умение, которое задело нескольких игроков, помечается **ПЛОЩАДЬ**; **СМЕРТЕЛЬНО** означает, что самый сильный полученный тобой от него удар на данный момент не меньше твоего текущего здоровья. Метр изучает каждое умение (площадное или нет, когда наносится урон) и помнит это между сессиями.
- **Цель цели:** блок, который можно целиком перемещать, менять в размере и масштабировать, а его части ещё и размещать по отдельности внутри него. Если выбранная клавишей Tab цель сама на кого-то нацелена, ты видишь, на кого: босса с картинкой и названием, игрока с эмблемой класса и именем. **Панель лекаря** (по желанию) добавляет в блок полосу здоровья этой цели и дебаффы (или баффы) на ней.

Разблокируй оверлей в **Настройки → Боевой оверлей**, чтобы расположить его: перетащи тело элемента, чтобы переместить, потяни за края, чтобы изменить размер, потяни за угол, чтобы масштабировать; ручка в правом нижнем углу всей рамки масштабирует все элементы сразу. В заблокированном состоянии он пропускает клики и виден, только когда игра на переднем плане. **Ctrl+Alt+C** включает и выключает его, как и горячая клавиша *Все оверлеи вкл / выкл*.

### Метр в вашем стриме (OBS, Streamlabs)

Показывайте метр в реальном времени поверх игры, не снимая его окно: включите **Настройки → Интерфейс → Оверлей для стрима (OBS) включён**, затем нажмите **Скопировать ссылку для OBS** (или в значке трея *Скопировать ссылку оверлея для стрима (OBS)*), добавьте в OBS или Streamlabs источник **Браузер**, вставьте ссылку и задайте размер источника. Страница следует за метром вживую: текущий вид (урон, лечение, полученный урон, всё в одном), игроки со значком класса и полосами и здоровье босса. Добавьте к ссылке `?scale=1.5` или `?rows=5`, чтобы увеличить его или показать меньше строк.

Он работает только на вашем ПК: сервер слушает `127.0.0.1` (снаружи вашего компьютера до него не добраться), ссылка содержит случайный ключ (после **Новый ключ** старая ссылка перестаёт работать), обслуживается только `GET`, страница ничего не загружает из других мест, и никому ничего не отправляется. Имена игроков **по умолчанию выключены** - каждый показан по своему классу, как в загрузках - и включаются в той же карточке настроек.

### Сессии

## Использование

Запись начинается, как только счётчик запущен. **Пауза отбрасывает** события, а не откладывает: всё, что произошло
во время паузы, пропадает, и возобновление никогда не воспроизводит бой, который вы пропустили.

- **Copy** кладёт в буфер однострочный рейтинг, готовый для чата (`Имя 1.234.567 (890), …`); **Copy All**
  даёт Markdown-таблицу для Discord.
- Внешний вид задаётся в **Настройки → Интерфейс**: тема (тёмная/светлая), размер шрифта, язык, вид оверлея
  и непрозрачность, запуск вместе с Windows.
- Ваши настройки переживут сбой: файл настроек записывается за один раз, а рядом хранится копия последнего запуска. Если файл когда-нибудь повредится, эта копия будет восстановлена (повреждённый файл сохраняется рядом). **Настройки → Интерфейс → Сбросить все настройки** спрашивает дважды, и сброс можно отменить в течение 30 секунд; ваш выбор по загрузкам и приватности, проверка обновлений и ваш персонаж остаются как есть.

## Загрузки

- **Бои с боссами** загружаются по нажатию «Загрузить» (кнопка на панели, меню Сессия или **Ctrl+Alt+U**): босс,
  участники, урон, лечение, полученный урон и умения. Принимаются только боссы, о которых сообщила игра и
  которых знает каталог. Автоматическая загрузка доступна и **выключена по умолчанию**.
- **Профиль вашего персонажа** (имя, класс, уровень, снаряжение, умения, Даэванион, легион, сервер, фракция)
  может загружаться автоматически через несколько секунд после входа, чтобы вас можно было найти на сайте. По умолчанию это
  **выключено**; включается в **Настройки**.
- Без загрузки ничто не покидает ваш компьютер.

## Обновления

Счётчик обновляется сам. При запуске и каждые пять минут во время работы он спрашивает GitHub о новой версии,
скачивает её в фоне и применяет при следующем запуске — без установщика и без запроса
UAC. Когда обновление готово, в строке состояния появляется зелёная строка (а на прозрачном
оверлее — значок); щелчок по ней предлагает сразу перезапустить. **Приложение → Проверить обновления** делает то же по запросу.
Старая версия продолжает загружать данные в течение 72 часов после выхода преемницы, затем её нужно обновить.

Проверка читает один URL и ничего не отправляет, кроме самого запроса:

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

Отключается в **Настройки → Обновления**; пункт меню работает и при этом.

## Сборка из исходников

```
cd Client
dotnet build
dotnet run -- selftest                              # самопроверки (протокол, захват, декодирование, ...)
dotnet run -- aion2-record <out.jsonl>              # записать трафик игры (завершается командой "stop")
dotnet run -- aion2-replay <file.jsonl>             # проиграть запись через настоящий декодер
dotnet run -- aion2-upload-dryrun <file.jsonl>      # собрать загрузки записи, ничего не отправляя
```

Только Windows (WPF). `Tools/aion2-dat` читает текстовые таблицы игры (названия на восьми языках); см. его README.

## О правилах серверов

Счётчик лишь пассивно наблюдает за сетевым трафиком самой игры. Тем не менее издатели устанавливают собственные
правила для сторонних инструментов — перед использованием стоит прочитать условия игры.
