# Aion DPS Meter

**Бесплатный счётчик DPS для AION 2** — урон и лечение всей группы в реальном времени, оверлей, пропускающий клики, рейтинги боссов, карта питомцев и сбора ресурсов, расписание событий и таймеры мировых боссов. Для Windows, с открытым кодом и никогда не читает память игры.

## Почему стоит выбрать

- DPS, iDPS и HPS в реальном времени для каждого игрока группы или рейда
- Оверлей, который не перехватывает клики
- Разбор умений с шансом крита и кривой DPS
- Рейтинги боссов и публичные профили персонажей на aiondps.com (загрузка по желанию, по умолчанию выключена)
- Интерактивная карта, расписание событий, таймеры мировых боссов и сетевой оверлей
- Безопасно: пассивный перехват пакетов, без чтения памяти и внедрения кода
- Бесплатно, с открытым кодом (MIT) и обновляется сам

Работает с глобальной версией AION 2 — со всеми регионами, запущенными NCSOFT 5 октября 2026 года. Корея и Тайвань на несколько версий впереди, поэтому там распознавание умений может быть неполным.

Счётчик урона/лечения и набор инструментов для **Aion 2**. Он читает сетевой трафик самой игры на вашем компьютере
через драйвер [Npcap](https://npcap.com) — пассивно: никогда не отправляет пакеты и не касается ни процесса игры, ни его
памяти. Ничего из вашей игры не покидает компьютер, пока вы сами это не загрузите (см.
[Загрузки](#загрузки)); кроме того, отправляется проверка обновлений — запрос к GitHub о более новой
версии, её можно отключить; см. [Обновления](#обновления).

## Установка

1. Установите драйвер [Npcap](https://npcap.com) (он нужен счётчику, чтобы видеть трафик игры; в установщик он
   не входит).
2. Скачайте `AionDpsMeter-win-Setup.exe` из [последнего релиза](../../releases/latest) и запустите. Он ставится
   в профиль пользователя и запускает счётчик — без прав администратора и без .NET.
3. Запустите счётчик, затем войдите в игру своим персонажем. Счётчик считывает персонажа, снаряжение, умения и доски
   Даэваниона из самой игры; сервер, на котором вы играете, определяется автоматически.

## Что он умеет

### Урон и лечение всех игроков в реальном времени

Каждый игрок вашей группы или рейда с именем, общим уроном, DPS и полосой доли; фракция и класс показаны
значками. Фильтр по классу, группе или цели. Фильтр **Mob/Boss** переключает между общим DPS и
настоящим **iDPS** по цели; боссы распознаются по данным самой игры и показываются по имени. Переключатель
**PvE/PvP** разделяет эти два режима, а вайп на боссе получает собственную запись (череп отмечает попытку,
после которой босс снова получил полное здоровье).

### Пять видов, один щелчок между ними

**Урон**, **Лечение**, **Полученный урон** и два вида **Всё вместе**. Переключайте горячей клавишей
(по умолчанию **Ctrl+Alt+M**) или щелчком по подписи режима в оверлее. *Всё вместе* показывает полученный урон,
лечение и общий урон рядом, *All in One Compact* сохраняет привычные столбцы DPS и общего урона, а лечение
и полученный урон выводит маленькой второй строкой под именем.

### Кликабельно-прозрачный оверлей

**Hide UI** превращает окно в маленькие плашки (или компактную панель), которые лежат поверх Aion 2 и не
перехватывают ни одного щелчка. Непрозрачность, полосы доли урона, здоровье босса и полученный урон по игрокам —
это настройки. Оверлей рисуется, только пока игра на переднем плане. Включайте его откуда угодно горячей клавишей.

### Разбивка по умениям для каждого игрока

**Двойной щелчок** по игроку: каждое умение с числом попаданий, шансом крита, суммой, минимумом, максимумом и средним,
с разбивкой по целям, плюс кривая DPS за весь бой. Шанс крита читается прямо из данных сервера о попаданиях, поэтому он точный.

### Весь ваш персонаж с первого взгляда

Окно **Персонаж** (значок человека) показывает то, что игра отправляет о вас: снаряжение с уровнем предметов и
заточкой (включая ступень Усиления выше +15), аркану, знания о видах, все умения с уровнями
и полные доски Даэваниона. Оно хранит ваш последний вход и потому никогда не пусто. Наведите курсор на предмет, чтобы увидеть
подробности (камни, выпавшие характеристики, камень бога).

### Интерактивная карта с питомцами и сбором

Оверлей-карта показывает вашу позицию, точки появления питомцев, за которыми вы охотитесь, и места сбора,
которые вы включили — травы, руды, дерево, самоцветы и другое — без переключения в браузер. В списке только то, чем
может воспользоваться ваша фракция, а последняя известная позиция остаётся на карте, пока игра закрыта. В настройках
питомцев перечислены все регионы Вертерона, Альтгарда и Бездны с их питомцами и вашим уровнем питомца, а также
вкладка **Редкие** для питомцев с малым числом точек появления. Стрелки у края указывают на ближайшего питомца или ресурс.

## Использование

Запись начинается, как только счётчик запущен. **Пауза отбрасывает** события, а не откладывает: всё, что произошло
во время паузы, пропадает, и возобновление никогда не воспроизводит бой, который вы пропустили.

- **Copy** кладёт в буфер однострочный рейтинг, готовый для чата (`Имя 1.234.567 (890), …`); **Copy All**
  даёт Markdown-таблицу для Discord.
- Внешний вид задаётся в **Настройки → Интерфейс**: тема (тёмная/светлая), размер шрифта, язык, вид оверлея
  и непрозрачность, запуск вместе с Windows.

## Горячие клавиши

Работают во всей системе, в том числе когда активна игра. Щёлкните поле в **Настройки → Горячие клавиши**, нажмите
нужную комбинацию (нужна Ctrl, Alt, Shift или Win); **×** удаляет её. Они заменяют команды чата,
которые не могут работать, потому что чат Aion 2 нельзя прочитать из сетевого трафика.

| По умолчанию | Действие |
|---|---|
| **Ctrl+Alt+H** | Оверлей (скрыть окно, показать плашки) |
| **Ctrl+Alt+P** | Пауза / продолжить |
| **Ctrl+Alt+D** | Копировать рейтинг |
| **Ctrl+Alt+Shift+X** | Очистить сессию |
| **Ctrl+Alt+U** | Загрузить урон по боссу |
| **Ctrl+Alt+M** | Следующий режим (пять видов) |
| **Ctrl+Alt+T** | Оверлей расписания |
| **Ctrl+Alt+K** | Интерактивная карта вкл / выкл |
| **Ctrl+Alt+E** / **Ctrl+Alt+G** | Стрелки у края для питомцев / ресурсов |
| **Ctrl+Alt+B** | Оверлей мировых боссов |
| **Ctrl+Alt+N** | Сетевой оверлей |
| **Ctrl+Alt+O** | Оверлей горячих клавиш (перемещаемый список горячих клавиш) |
| **Ctrl+Alt+A** | Все оверлеи вкл / выкл |

## Загрузки

- **Бои с боссами** загружаются по нажатию «Загрузить» (кнопка на панели, меню Сессия или **Ctrl+Alt+U**): босс,
  участники, урон, лечение, полученный урон и умения. Принимаются только боссы, о которых сообщила игра и
  которых знает каталог. Автоматическая загрузка доступна и **выключена по умолчанию**.
- **Профиль вашего персонажа** (имя, класс, уровень, снаряжение, умения, Даэванион, легион, сервер, фракция)
  может загружаться автоматически через несколько секунд после входа, чтобы вас можно было найти на сайте. По умолчанию это
  **выключено**; включается в **Настройки**.
- Без загрузки ничто не покидает ваш компьютер.

## Обновления

Счётчик обновляется сам. При запуске и каждые пять минут во время работы он спрашивает GitHub о новой версии,
скачивает её в фоне и применяет при следующем запуске — без установщика и без запроса
UAC. Когда обновление готово, в строке состояния появляется зелёная строка (а на прозрачном
оверлее — значок); щелчок по ней предлагает сразу перезапустить. **Приложение → Проверить обновления** делает то же по запросу.
Старая версия продолжает загружать данные в течение 72 часов после выхода преемницы, затем её нужно обновить.

Проверка читает один URL и ничего не отправляет, кроме самого запроса:

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

Отключается в **Настройки → Обновления**; пункт меню работает и при этом.

## Сборка из исходников

```
cd Client
dotnet build
dotnet run -- selftest                              # самопроверки (протокол, захват, декодирование, ...)
dotnet run -- aion2-record <out.jsonl>              # записать трафик игры (завершается командой "stop")
dotnet run -- aion2-replay <file.jsonl>             # проиграть запись через настоящий декодер
dotnet run -- aion2-upload-dryrun <file.jsonl>      # собрать загрузки записи, ничего не отправляя
```

Только Windows (WPF). `Tools/aion2-dat` читает текстовые таблицы игры (названия на восьми языках); см. его README.

## О правилах серверов

Счётчик лишь пассивно наблюдает за сетевым трафиком самой игры. Тем не менее издатели устанавливают собственные
правила для сторонних инструментов — перед использованием стоит прочитать условия игры.
