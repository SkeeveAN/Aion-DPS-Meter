# Aion DPS Meter

Сайт с общими рейтингами боссов и профилями персонажей: **https://aiondps.com**

Счётчик урона/лечения для **Aion 2**. Он читает сетевой трафик игры на вашем компьютере через драйвер
[Npcap](https://npcap.com) — пассивно: никогда не отправляет пакеты и не касается ни процесса игры, ни его памяти.
Ничего из вашей игры не покидает компьютер, пока вы сами это не загрузите (см. [Загрузки](#загрузки)); кроме того,
отправляется проверка обновлений — запрос к GitHub о более новой версии, её можно отключить; см. [Обновления](#обновления).

> Классический Aion (на основе Chat.log) больше не входит в счётчик. Последняя версия с его поддержкой хранится в
> ветке [`aion1-included`](../../tree/aion1-included).

## Установка

1. Установите драйвер [Npcap](https://npcap.com) (он нужен счётчику, чтобы видеть трафик игры; в установщик он не входит).
2. Скачайте `AionDpsMeter-win-Setup.exe` из [последнего релиза](../../releases/latest) и запустите. Он ставится в
   профиль пользователя и запускает счётчик — без прав администратора и без .NET.
3. Запустите счётчик и войдите в игру своим персонажем. Счётчик считывает персонажа, снаряжение, умения и доски
   Даэваниона из самой игры; сервер определяется автоматически.

## Использование

Запись начинается, как только счётчик запущен. **Пауза отбрасывает** события, а не откладывает: всё, что произошло
во время паузы, пропадает, и возобновление никогда не воспроизводит бой, который вы пропустили.

### Вид

- **Dmg** — урон по игрокам с суммой и DPS, значками классов и сортируемым списком. Фильтр **Mob/Boss** переключает
  столбец между общим DPS и настоящим **iDPS** по цели. Боссы распознаются по данным игры и показываются по имени.
  **Двойной щелчок** по игроку открывает разбивку по умениям.
- **Персонаж** (значок человека) — открывает окно с вашим персонажем: профиль, снаряжение с уровнями предметов и
  заточкой, умения с уровнями и доски Даэваниона. Окно хранит ваш последний вход и потому никогда не пусто.

### Hide UI (оверлей)

Превращает окно в маленькие кликабельно-прозрачные плашки поверх игры — по одной на игрока: имя, урон и DPS.
Переключается **Ctrl+Alt+H** откуда угодно.

### Копирование

**Copy** кладёт в буфер однострочный рейтинг, готовый для чата (`Имя 1.234.567 (890), …`); **Copy All** даёт
Markdown-таблицу для Discord.

### Горячие клавиши

Работают везде, в том числе когда активна игра (меняются в **Настройки → Интерфейс → Горячие клавиши**): **Ctrl+Alt+H** оверлей, **Ctrl+Alt+P** пауза / продолжить, **Ctrl+Alt+D** копировать рейтинг, **Ctrl+Alt+Shift+X** очистить сессию. Они заменяют команды чата, которые не могут работать, потому что чат Aion 2 нельзя прочитать из сетевого трафика.

## Загрузки

- **Бои с боссами** загружаются по нажатию «upload» (кнопка или меню Session): босс, участники, урон, лечение,
  полученный урон и умения. Принимаются только боссы, о которых сообщила игра и которых знает каталог.
- **Профиль вашего персонажа** (имя, класс, уровень, снаряжение, умения, Даэванион, легион, сервер) может
  загружаться автоматически через несколько секунд после входа, чтобы вас можно было найти на сайте. По умолчанию это
  **выключено**; включается в **настройках**.
- Без загрузки ничто не покидает ваш компьютер.

## Обновления

Счётчик обновляется сам. При запуске и каждые пять минут он спрашивает GitHub о новой версии, скачивает её в фоне и
применяет при следующем запуске — без установщика и без UAC. Когда обновление готово, внизу появляется зелёная
строка; щелчок предлагает сразу перезапустить. **App → Check for updates** делает то же по запросу.

Проверка читает один URL и ничего не отправляет, кроме самого запроса:

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

Отключается в **Настройки → Обновления**; пункт меню работает и при этом.

## Сборка из исходников

```
cd Client
dotnet build
dotnet run -- selftest                              # самопроверки (протокол, захват, декодирование, ...)
dotnet run -- aion2-record <out.jsonl>              # записать трафик игры (завершается командой "stop")
dotnet run -- aion2-replay <файл.jsonl>             # проиграть запись через настоящий декодер
dotnet run -- aion2-upload-dryrun <файл.jsonl>      # собрать загрузки записи, ничего не отправляя
```

Только Windows (WPF). `Tools/aion2-dat` читает текстовые таблицы игры (названия на восьми языках); см. его README.

## О правилах серверов

Счётчик лишь пассивно наблюдает за сетевым трафиком игры. Тем не менее издатели устанавливают собственные правила
для сторонних инструментов — перед использованием стоит прочитать условия игры.
