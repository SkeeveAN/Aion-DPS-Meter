# Aion DPS Meter

Счётчик урона и добычи для **AION 4.6 (OriginAion)**, работающий исключительно на основе
собственного файла `Chat.log` игры.

Программа читает текстовый файл, который клиент пишет сам. Она не перехватывает сетевой трафик
и не читает и не записывает ничего в процессе игры. Ничего из вашей игры не покидает ваш
компьютер — ни цифры урона, ни добыча, ни имена. Единственное, что программа отправляет — это
проверка обновлений, которая спрашивает GitHub о новой версии и которую можно отключить; см.
[Обновления](#обновления).

## Установка

1. Скачайте `AionDpsMeter-win-Setup.exe` из [последнего релиза](../../releases/latest) и
   запустите его. Ничего нажимать не нужно — установка выполняется в профиль пользователя и
   сразу запускает счётчик. Без прав администратора, без .NET.
2. Откройте **Settings → App Settings** и укажите **папку установки Aion** — корневую папку,
   содержащую `bin64\game.dll`. Окно сразу сообщит, найдена ли действительная установка и есть
   ли там уже файл `Chat.log`.

> **Обновляетесь с версии 0.5.2 или старше?** Сначала удалите старую версию (Параметры Windows →
> Приложения → *Aion DPS Meter*), затем запустите новый установщик. Те версии устанавливались в
> `Program Files`, из-за чего никогда не могли обновляться сами. Это разовый шаг — дальше
> обновления применяются автоматически.

### Требование: ведение чат-лога клиента должно быть включено

Aion записывает `Chat.log` только при включённой внутренней опции клиента `g_chatlog`. Этот
переключатель находится в игровом клиенте, а не в этой программе — включите его так, как обычно
(например, через [ShugoConsole](https://github.com/grenadium/ShugoConsole)). **Aion DPS Meter
никогда не трогает процесс игры для этого**; если файл не пишется, счётчику нечего читать.

## Использование

Запись начинается сразу, как только счётчик запущен и указана действительная папка Aion.

**Программа никогда не читает вашу историю чата.** При запуске она переходит к *текущему* концу
файла `Chat.log` и обрабатывает только строки, записанные с этого момента — как магнитофон,
который только что включили, а не сканер архива. **Пауза отбрасывает**, а не откладывает: строки,
записанные во время паузы, пропускаются навсегда, поэтому возобновление никогда не воспроизводит
бой, который вы сознательно пропустили. Ваши прошлые личные разговоры, чат легиона и шёпот никогда
не просматриваются.

### Виды

- **Dmg** — урон по каждому игроку с суммой и DPS, значками классов и сортируемым списком.
  Фильтр **Mob/Boss** переключает столбец между общим DPS и настоящим целевым **iDPS** (урон по
  одной цели, делённый на общее время боя группы с этой целью).
- **Loot** — что кому выпало: игрок, предмет, количество и степень редкости. Реликвии также
  засчитываются в Очки Бездны соответствующего игрока.

### Hide UI (наложение)

Превращает окно в маленькие, прозрачные для кликов «чипы», которые можно оставить поверх игры —
по одному на игрока, с именем, уроном и DPS. Переключается **Ctrl+Alt+H** из любого места, так
что это никогда не дорога в один конец.

### Copy

**Copy** помещает в буфер обмена однострочный, готовый для чата рейтинг
(`Имя 1.234.567 (890), …`). В виде Loot вместо этого создаётся сводка добычи для чата Aion, а
**Copy All** даёт таблицу в формате Markdown для Discord.

### Команды в игре

Введите их как обычные строки чата, чтобы управлять счётчиком, не выходя из игры:

| Команда | Действие |
|---|---|
| `.ui` | переключить наложение Hide-UI |
| `.pause` / `.resume` | остановить / возобновить запись |
| `.dmg` | скопировать рейтинг урона в буфер обмена |
| `.cleardmg` | очистить текущую сессию |
| `.loot` | скопировать сводку добычи в буфер обмена |

Их могут вызывать только персонажи, зарегистрированные в настройках, поэтому `.cleardmg`,
введённый посторонним в канале, который вы даже не читаете, не может стереть вашу сессию.

## Обновления

Счётчик обновляется сам. При запуске, а затем каждые пять минут, он спрашивает GitHub о новой
версии, загружает её в фоне и подменяет при следующем запуске. Без установщика, без окна UAC,
ничего нажимать не нужно. Это работает, потому что программа находится в профиле пользователя, а
не в `Program Files` — там ей разрешено заменять собственные файлы.

Когда обновление уже загружено, внизу в строке состояния появляется зелёная строка; клик по ней
предлагает немедленный перезапуск. Отказ ничего не стоит — версия уже там и включится при
следующем обычном запуске. Всплывающего окна намеренно нет: окно программы лежит поверх
запущенной игры, и диалог, крадущий фокус посреди боя с боссом, был бы хуже, чем позднее
обновление.

**App → Check for updates** делает то же самое по запросу и также сообщает, если у вас уже
последняя версия.

Проверка читает ровно один URL и не отправляет ничего, кроме самого запроса:

```
https://api.github.com/repos/SkeeveAN/Aion-DPS-Meter/releases
```

Отключается в **Settings → App Settings → Updates**. Пункт меню продолжает работать — это ваш
собственный запрос, а не решение программы.

## Насколько это точно?

Проверено на трёх файлах `Chat.log` от одного и того же прохождения Sauro Supply Base, записанных
на трёх разных компьютерах (один из них — немецкий клиент), с реальными HP боссов в качестве
эталона. Урон по боссу отличается от его реальных HP на **0,02% – 2,8%**:

| Босс | Реальные HP | Измерено | Отклонение |
|---|---|---|---|
| Командир стражи Ахурадим | 1 736 993 | 1 737 299 | +0,02% |
| Тёмный пожиратель Деракaнак | 1 343 657 | 1 347 258 | +0,27% |
| Офицер инспекции Саяхум | 1 377 644 | 1 370 734 | −0,50% |
| Комендант снабжения Ранодим | 489 332 | 503 244 | +2,84% |

Остальное — превышение при добивающем ударе, которое ни один счётчик на основе лога увидеть не
может. Общий урон игрока совпадал до единицы на всех трёх компьютерах.

Два известных, безобидных отклонения: у босса, чей щит поглощает урон, этот урон всё равно
логируется (из-за чего итог превышает его HP), а несколько мобов с одинаковым именем
суммируются вместе.

## Сборка из исходного кода

```
dotnet build
dotnet run -- selftest                    # внутренние тесты парсера и расчёта DPS
dotnet run -- chatlog <путь-к-Chat.log>   # разобрать файл и вывести сводку
```

Только Windows (WPF). Внутренние тесты прогоняют дословные строки из реальных логов на всех
поддерживаемых языках и являются самым быстрым способом узнать, не сломало ли что-то изменение
парсера.

## Замечание о правилах сервера

Эта программа читает только файл журнала, который создаёт сама игра. Тем не менее у приватных
серверов есть собственные правила насчёт стороннего ПО и аддонов — стоит заглянуть в правила
OriginAion перед использованием.
